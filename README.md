# Insurance Claims Data Platform

## Overview

An end-to-end data engineering platform for insurance analytics.

This project demonstrates data ingestion, transformation, data quality validation, dimensional modeling, and analytics.

## Technology Stack

- Python
- SQL
- PySpark
- Apache Spark
- Azure Data Factory
- Azure Data Lake Storage
- Azure Databricks
- Delta Lake
- Power BI

## Architecture

↓
